## Data

All data is synthetic, generated by `src/datagen/generate.py` from fixed seed
`20260408`. No real, customer, scraped or third-party data appears anywhere in
this repository. Re-running the generator with the same seed reproduces the
landing zone exactly.

## Foundation model

Model-serving endpoints are resolved **at runtime** from the preference list in
`src/config.py:FMAPI_ENDPOINT_PREFERENCE`; no endpoint name is hardcoded in
notebook or application code. The endpoint actually selected for each run is
recorded in `evidence/04_genai_agent.md`.

## How notebook outputs were produced

Notebooks are authored in jupytext percent format as `notebooks/*.py` and
executed cell-by-cell against the live cluster through the Databricks Command
Execution API by `tools/dbx_notebook.py`, inside a single execution context so
state carries across cells as in an interactive session. Whatever the cluster
returns is captured verbatim into the committed `.ipynb` and mirrored to
`notebooks/exports/*.md`.

No output in this repository was written, edited or synthesised by hand. A
failing cell is captured as an error output and halts the run, so a committed
notebook cannot show a passing cell that did not actually run.
